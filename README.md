# Supermart-Grocery-Sales-Dashboard
Interactive Excel dashboard for Supermart Grocery Sales analysis, covering sales performance, product analysis, profit, discounts and geographic insights.

##  Project Overview

The **Supermart Grocery Sales Dashboard** is an Excel-based data analytics project designed to analyze grocery sales data and provide meaningful business insights.

The dashboard helps management understand sales performance, profitability, product performance, discount impact, and geographical sales distribution through interactive charts and KPI indicators.

##  Project Objectives

1. Analyze overall sales and profit performance.
2. Identify top-performing product categories and sub-categories.
3. Understand the relationship between discounts and profitability.
4. Analyze sales and profit across different regions and cities.
5. Present business insights through an interactive Excel dashboard.

## Tools & Technologies

- Microsoft Excel
- Excel Charts
- Pivot-style data analysis and summary calculations
- Interactive dropdown filters
- CSV Dataset

##  Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Monthly Sales and Profit Trends
- Sales by Product Category
- Sales and Profit by Region
- Sub-category Sales Analysis
- Discount Performance Analysis
- Interactive filters for Year, Region, and Category

##  Dataset Information

- Total Records: 9,994
- Dataset Type: Retail Grocery Sales
- Time Period: 2015–2018
- Data Format: CSV

The dataset contains information about orders, customers, product categories, sub-categories, sales, discounts, profits, cities, states, and regions.

##  Key Business Questions

- Which product categories generate the highest sales?
- Which products and sub-categories contribute the most profit?
- How do sales and profits change over time?
- Which regions generate the highest revenue?
- How do discounts relate to profitability?
- Which cities contribute most to business performance?

##  How to Use the Dashboard

1. Download the Excel dashboard from this repository.
2. Open it using Microsoft Excel.
3. Navigate to the **Dashboard** worksheet.
4. Use the dropdown filters to select Year, Region, and Category.
5. Explore the KPI cards and charts to understand business performance.
6. Visit the Raw Data worksheet to explore the original dataset.

##  Important Data Note

The supplied dataset contains records from Tamil Nadu only. Therefore, city-level comparisons are included instead of state-level comparisons.
